## Reading the columns

- **Lean / Reliability** are provisional analyst assessments, informed by MBFC where available.
- **System type** is the value that maps to the current `FeedSource.sourceType`.
- **Feed** reflects the primary validated feed(s), not every tested alternative.
- **Action** is derived from the feed registry; `No public feed` means no verified official RSS.
- **Region** uses the research template’s `sourceRegion` value. `Latin America` is shown for the template’s `South America` value.
